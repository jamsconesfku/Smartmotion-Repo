# Software licences

Consumer game licences do **not** allow paid public use. Live status is in `data/licences.json`.

| Software | Use | Commercial route | Cost / status |
|---|---|---|---|
| **X-Plane 12 Professional** | Flight | Buy direct from x-plane.com. A professional key is required whenever X-Plane generates revenue. | $1,000 digital; $1,250 USB key (works offline) |
| **DCS World** | Jets and warbirds | Separate commercial site licence from Eagle Dynamics (support@digitalcombatsimulator.com). VR Sim holds one, so there's a precedent. | By quote |
| **Assetto Corsa Commercial Pro** | Track and rally (rally via mods) | Authorised resellers only (Vesaro, FPZERO). Pro tier allows third-party software like FlyPT Mover. | About £3,750 per simulator, one-off |
| **rFactor 2** | Circuit racing | info@motorsportgames.com | By quote |
| **FlightGear** | Flight (open source, GPL) | Free; paid use allowed | Free; candidate base for a custom sim |
| **FlyPT Mover** | Motion control | Confirm commercial use with the developer (XSimulator forum) | To confirm |
| Microsoft Flight Simulator 2024 | – | No commercial licence available | **Not usable** for paid sessions |
| Prepar3D | – | Licensed for training, not entertainment | Not suitable |
| Automobilista 2, EA WRC, DiRT Rally | – | No commercial licence found | Not usable |

- Third-party aircraft, scenery and mods each need **separate written permission**.
- Advertise experiences **by type** ("Fast Jet Low-Level", "WW2 Fighter Sortie", "Rally Stage"), not by game or brand name.
- Recommended first licences (DEC-04): X-Plane Pro now; ask Eagle Dynamics about DCS; Assetto Corsa Commercial Pro for driving.
